--region 【生命周期】

---唤醒
---@type fun():void
---@desc 注册按钮监听（self:AddUIListener 随界面销毁自动注销）
--TODO: [优化] 按钮监听由 AddUIListenerBatch 改为 self:AddUIListener 逐条（自动注销）
function UIMainStateViewView:Awake()
    UIMainStateViewView.super.Awake(self)
    self:AddUIListener(self.SettingButton, 'Clicked', Bind(self, self.OnSettingButtonClicked))
    self:AddUIListener(self.LevelButton, 'Clicked', Bind(self, self.OnLevelButtonClicked))
    self:AddUIListener(self.DailyChallengeButton, 'Clicked', Bind(self, self.OnDailyChallengeButtonClicked))
end

---初始化回调（在Awake中ViewSuper首次调用SetViewModel时触发，该方法执行后才会调用为View设置ViewModel，因此请勿在该方法中调用GetViewModel。）
---@type fun(viewModel:UIMainStateViewViewModel):void
---@param viewModel UIMainStateViewViewModel @ViewModel
function UIMainStateViewView:OnInit(viewModel)
    UIMainStateViewView.super.OnInit(self, viewModel)
    -- 无数据变化监听
    LevelManager:GetCurrentLevelInfo()
    self.LevelTxt.text = viewModel:GetChapterLevel()
end

---开始
---@type fun():void
function UIMainStateViewView:Start()
    UIMainStateViewView.super.Start(self)
end

---销毁
---@type fun():void
---@desc UI 监听由 ViewSuper:OnDestroy 自动注销（self:AddUIListener 记录），此处无需手动 OnRemoveListenerBatch
function UIMainStateViewView:OnDestroy()
    UIMainStateViewView.super.OnDestroy(self)
end

---注册监听代码处（注：所有成员函数的注册监听代码都写在这里，成员函数作为监听回调时不需要手动注销，父类会自动辅助完成事件的注销操作。）
---@type fun():void
function UIMainStateViewView:OnAddListeners()

end
