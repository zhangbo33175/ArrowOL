## 三、功能设计

### RankDataManager（数据层）
- 全局单例（`Singleton` 基类），随 `GameRequires` 启动自动创建。
- 数据来源：本地模拟榜单（20 名玩家，`InitMockRankList`）+ 玩家自身成绩。
- 接口一览：
  - `GetRankList()`：合并榜单 + 玩家自身，按分数降序并附加 `rank` 字段（同分时玩家自身优先）。
  - `GetPlayerRank()`：玩家排名（1 起，未进榜返回 -1）。
  - `GetPlayerScore()` / `UpdatePlayerScore(score)`：玩家分数读写。
  - `GetPlayerName()`：玩家昵称（优先 `PlayerInfoDataManager:GetPlayerInfoUserName()`，兜底「我」）。
- 持久化：玩家分数经 `GameMainRoot.Persist`（PlayerPrefs）独立存取（key：`RankDataManager.playerScore`），**不侵入自动生成的 GameDataPB 存档结构**。
- 所有外部依赖均做空值防护 + `xpcall` 包裹 + `PrintError` 上报，符合现有 SettingDataManager 范式。

### UIRankView（界面层）
- 字段绑定（Prefab 需按注释结构提供）：
  - `CloseButton`（Button，Clicked）— 关闭排行榜
  - `RankRoot`（Transform）— RankItem 列表容器父节点
  - `PlayerRankText` / `PlayerScoreText`（TextMeshProUGUI）— 我的排名 / 我的分数
- 生命周期：Awake 绑定关闭按钮 → Start 刷新玩家信息与榜单 → OnDestroy 注销监听。
- 榜单刷新：`ClearRankRoot()` 清空旧子项后，按榜单数据逐条 `AddUISync(UIs.RankItem, RankRoot, {data = ...})` 创建条目。

### RankItem（列表项层）
- 构造入参 `args.data`（结构：`{rank, name, score, isSelf}`）。
- Start 阶段 `Refresh()` 刷新名次/昵称/分数，并控制 `SelfMark`（自己高亮标识）显隐。

## 四、接入步骤（资源侧）

1. **创建 Prefab**：在 `Assets\Res\Prefabs\UIs\` 下新建 `UIRankView`（或 `UIRankView.prefab`），按 `UIRankView.lua.txt` 顶部 `---@field` 注释搭建节点：`CloseButton`、`RankRoot`、`PlayerRankText`、`PlayerScoreText`。
2. **创建 RankItem Prefab**：`RankRoot` 下的子项预制体，含 `RankText` / `NameText` / `ScoreText` / `SelfMark` 节点。
3. **挂 Lua 脚本**：将 `UIRankView.lua.txt` 挂到 UIRankView 预制体 LuaBehaviour 上；将 `RankItem.lua.txt` 挂到 RankItem 预制体上（参照 UILoadMapView / UISettlementView 的挂法）。
4. **导出 UIs 表**：通过 `ResDefExportEditorWindow` 资源导出工具生成 UIs 配置，使 `UIs.UIRankView` 与 `UIs.RankItem` 条目自动写入 `UIs.lua.txt`（该文件自动生成，禁止手改）。
5. 完成上述步骤后，主界面点击「排行」按钮即可打开排行榜。

## 六、后续扩展建议

- **接入服务器排行榜**：替换 `RankDataManager:InitMockRankList()` 数据源为网络请求结果，保留 `GetRankList()` / `GetPlayerRank()` 对外接口不变，UI 层无需改动。
- **跨界面分数联动**：在关卡结算处调用 `RankDataManager:UpdatePlayerScore(score)` 即可让排行榜实时反映最新成绩。
- **榜单分页**：若榜单条目增多，可在 `GetRankList()` 内按 `MaxRankCount` 截断（当前 20 条），或扩展为分段拉取。
