## 二、分层架构设计模式

框架采用 **Component（组件）- Manager（管理器）- Helper（辅助）** 三层模式：

| 层 | 职责 | 示例 |
|----|------|------|
| **Component** | 挂载在场景物体上，提供对外 API 入口，继承 `GameComponent` 自动注册 | `SceneComponent`、`UIComponent` |
| **Manager** | 纯 C# 核心逻辑实现，由 Component 实例化持有 | `SceneManager`、`UIManager` |
| **Helper/Agent** | 底层资源封装（音频代理、加载器） | `SoundAgent`、`PrefabLoadManager` |

访问约定：所有系统通过 `GameMainRoot.XXX`（如 `GameMainRoot.Scene`）统一访问，
组件通过 `GameComponentsGroup.GetComponent<T>()` 注册与获取，遵循单类型单例原则。

### 2. 命名规范
| 项 | 规则 | 示例 |
|----|------|------|
| 命名空间 | `Honor.Runtime` / `Honor.Editor` | `namespace Honor.Runtime` |
| 类/方法/属性 | PascalCase | `SceneComponent`、`LoadSceneAsync` |
| 私有字段 | `m_` + PascalCase | `m_SceneManager`、`m_CameraRtMap` |
| 静态字段 | `s_` 或 `m_` + PascalCase | `m_Instance`、`m_Lock` |
| 常量 | PascalCase | `GameConstants` |
| 局部变量 | camelCase | `camera`、`rt` |
| 参数 | camelCase | `abPath`、`assetName` |
| 禁止 | `_` 前缀字段（已全部清理） | ~~`_timers`~~ → `m_Timers` |

### 3. 结构组织
- 类内使用 `#region` 分区：`#region 生命周期` / `#region 公共方法` / `#region 私有方法`
- partial 类按职责拆分为 `Xxx.cs`（主类）+ `Xxx.Methods.cs`（方法）+ `Xxx.Visitors.cs`（属性/序列化字段）
- 所有公开成员必须有 XML 文档注释（`/// <summary>`、`<param>`、`<returns>`）

### 4. 防御性编程
- 公开方法入口做参数空值校验（null 检查 + `Log.Error` 或 `GameException`）
- 场景对象销毁前检查 Unity 生命周期状态（`== null` 可检测已销毁对象）
- 集合遍历中移除元素使用倒序 for 循环

## 七、注意事项

1. **XLua 生成**：`MonoSingleton`/`Singleton` 等泛型基类未变更公共成员，无需重新生成 Wrap；
   若 IDE 提示 XLua 缓存过期，可在 Unity 菜单重新执行 XLua 生成。
2. **命名替换影响面**：字段重命名已同步全部跨 partial 文件引用（Tree、AssetLoadManager、UIManager 系列），
   无外部 API 暴露（均为 private/protected），Lua 侧不受影响。
3. **Shader 属性**：AorTextEffect 系列中的 `_OutlineColor`、`_Max`、`_Min` 等为材质属性名，切勿改动。
